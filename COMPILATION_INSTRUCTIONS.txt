🔧 HOW TO COMPILE TO PDF:
══════════════════════════

METHOD 1: Using Online LaTeX Editor (EASIEST)
----------------------------------------------
1. Go to https://www.overleaf.com (free account)
2. Create "New Project" → "Blank Project"
3. Delete the default content
4. Upload: GATE_2026_Physics_Complete_Guide.tex
5. Click "Recompile" button
6. Download PDF

METHOD 2: Using Local LaTeX Installation
-----------------------------------------
If you have LaTeX installed on your computer:

# For Windows/Linux/Mac:
pdflatex GATE_2026_Physics_Complete_Guide.tex
pdflatex GATE_2026_Physics_Complete_Guide.tex  # Run twice for TOC

# Or use XeLaTeX:
xelatex GATE_2026_Physics_Complete_Guide.tex
xelatex GATE_2026_Physics_Complete_Guide.tex

METHOD 3: Using LaTeX Editors
------------------------------
• TeXstudio: Open file → Press F5
• TeXmaker: Open file → Click "Quick Build"
• VS Code: Install LaTeX Workshop extension → Open file → Save
