WHAT EACH FILE DOES
===================

twister_spin_networks.tex:
  Main LaTeX document covering twistor theory and spin networks
  comprehensively with full mathematical treatment.

mathematical_supplement.tex:
  Detailed calculations, derivations, and numerical examples
  for both twistor theory and spin networks.

twistor_visualization.py:
  Manim script with 8 scenes visualizing twistor theory concepts:
  complex projective space, incidence relations, Penrose transform, etc.

spin_network_visualization.py:
  Manim script with 10 scenes visualizing spin network concepts:
  graph structures, SU(2) reps, area quantization, 6j-symbols, etc.

combined_visualization.py:
  Manim script with 6 scenes showing connections between both theories
  and presenting a unified framework.

README_VISUALIZATION.md:
  Complete reference manual with installation, compilation, rendering
  instructions, troubleshooting, and full documentation.

QUICKSTART.md:
  Quick start guide to get up and running in 5 minutes with
  learning paths and common commands.

PROJECT_OVERVIEW.md:
  High-level project summary with statistics, technical specs,
  and complete overview of all deliverables.

Makefile:
  Build automation with 30+ targets for compiling LaTeX,
  rendering Manim scenes, and managing the project.

requirements.txt:
  Python package dependencies for Manim and visualization tools.
  Install with: pip install -r requirements.txt

verify_setup.sh:
  Bash script that checks all dependencies, validates syntax,
  and provides setup guidance.
