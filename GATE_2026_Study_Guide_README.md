## ⚡ Quick Formula Reference

### Quantum Mechanics Essentials ⭐
```
[x̂, p̂ₓ] = iℏ
[L̂ᵢ, L̂ⱼ] = iℏεᵢⱼₖL̂ₖ

E_n (well) = n²π²ℏ²/(2mL²)
E_n (HO) = ℏω(n + 1/2)

â|n⟩ = √n|n-1⟩
â†|n⟩ = √(n+1)|n+1⟩

L̂²|l,m⟩ = ℏ²l(l+1)|l,m⟩
L̂ᵤ|l,m⟩ = ℏm|l,m⟩

E_n⁽¹⁾ = ⟨n|Ĥ'|n⟩  (1st order perturbation)
```

### Mathematical Physics Essentials
```
∇φ = (∂φ/∂x, ∂φ/∂y, ∂φ/∂z)
∇·F = ∂Fx/∂x + ∂Fy/∂y + ∂Fz/∂z
∇×F = (∂Fz/∂y - ∂Fy/∂z, ...)

f(z₀) = (1/2πi)∮ f(z)/(z-z₀) dz
∮ f(z)dz = 2πi Σ Res(f, zₖ)

∫₋₁¹ Pₘ(x)Pₙ(x)dx = 2/(2n+1) δₘₙ
```

### Classical Mechanics Essentials
```
L = T - V
d/dt(∂L/∂q̇ᵢ) - ∂L/∂qᵢ = 0

H = Σpᵢq̇ᵢ - L
q̇ᵢ = ∂H/∂pᵢ,  ṗᵢ = -∂H/∂qᵢ

r = l/(1 + e cosθ)  [Kepler orbit]
T² = (4π²/GM)a³    [Kepler's 3rd law]

I = Iᶜᴹ + Md²      [Parallel axis theorem]
```
