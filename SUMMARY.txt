QUICK START
===========

1. Install Dependencies
   --------------------
   # LaTeX (choose your OS)
   Ubuntu/Debian: sudo apt install texlive-full
   macOS:         brew install --cask mactex
   Windows:       Download from https://miktex.org/

   # Python/Manim
   pip install -r requirements.txt

2. Verify Setup
   ------------
   ./verify_setup.sh

3. Compile LaTeX
   -------------
   make latex
   # Output: twister_spin_networks.pdf, mathematical_supplement.pdf

4. Render Animations
   -----------------
   # Quick preview (low quality, fast)
   make manim-preview

   # High quality (slower, ~2-4 hours for all)
   make manim-all

   # Individual scenes
   manim -pqh twistor_visualization.py ComplexProjectiveSpace
   manim -pqh spin_network_visualization.py BasicSpinNetwork

5. View Results
   ------------
   PDFs:   twister_spin_networks.pdf, mathematical_supplement.pdf
   Videos: media/videos/*/1080p60/*.mp4
