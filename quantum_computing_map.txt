┌─────────────────────────────────────────────────────────────────────┐
│ 1. CORE CONCEPTS                                                     │
└─────────────────────────────────────────────────────────────────────┘

   • Qubits (vs classical bits)
     - Superposition: |0⟩ + |1⟩
     - Entanglement: Bell states
     - Measurement: collapses state

   • Quantum Gates
     - Pauli gates (X, Y, Z)
     - Hadamard (H)
     - CNOT (entanglement)
     - Phase gates

   • Quantum Circuits
     - Unitary operations
     - Reversibility
     - No-cloning theorem


┌─────────────────────────────────────────────────────────────────────┐
│ 2. HARDWARE ARCHITECTURES                                            │
└─────────────────────────────────────────────────────────────────────┘

   Superconducting (IBM, Google)
   ├─ Transmon qubits
   ├─ Microwave control
   └─ Cryogenic temps (~20mK)

   Trapped Ions (IonQ, Honeywell)
   ├─ Yb+, Ca+ ions
   ├─ Laser control
   └─ Long coherence times

   Photonic (Xanadu, PsiQuantum)
   ├─ Quantum optics
   ├─ Room temp operation
   └─ Linear optical circuits

   Neutral Atoms (ColdQuanta, QuEra)
   ├─ Rydberg states
   ├─ Optical tweezers
   └─ Programmable arrays

   Topological (Microsoft)
   ├─ Anyons
   ├─ Error-resistant
   └─ Still theoretical


┌─────────────────────────────────────────────────────────────────────┐
│ 3. KEY ALGORITHMS                                                    │
└─────────────────────────────────────────────────────────────────────┘

   Shor's Algorithm
   └─ Factoring → breaks RSA encryption
      O(log³ N) vs classical O(e^N)

   Grover's Algorithm
   └─ Unstructured search
      O(√N) vs classical O(N)

   Quantum Approximate Optimization (QAOA)
   └─ Combinatorial optimization
      Max-cut, TSP, etc.

   Variational Quantum Eigensolver (VQE)
   └─ Chemistry simulations
      Molecular ground states

   Quantum Machine Learning
   ├─ Quantum neural networks
   ├─ Quantum kernels
   └─ Hybrid classical-quantum

┌─────────────────────────────────────────────────────────────────────┐
│ 5. ERROR CORRECTION & NOISE                                          │
└─────────────────────────────────────────────────────────────────────┘

   Challenges:
   • Decoherence (T1, T2 times)
   • Gate errors (~0.1-1%)
   • Measurement errors
   • Crosstalk between qubits

   Solutions:
   • Surface codes (most promising)
   • Stabilizer codes
   • Fault-tolerant thresholds
   • Error mitigation techniques

   Threshold Theorem:
   └─ If error rate < ~1%, can correct
      exponentially → need 100-1000s
      physical qubits per logical qubit


┌─────────────────────────────────────────────────────────────────────┐
│ 6. QUANTUM SUPREMACY / ADVANTAGE                                     │
└─────────────────────────────────────────────────────────────────────┘

   Google (2019): Sycamore
   └─ 53 qubits, random circuit sampling
      "200 seconds vs 10,000 years"

   Chinese (2020): Jiuzhang
   └─ Photonic, boson sampling

   Current Status:
   • NISQ era (Noisy Intermediate Scale)
   • ~100-1000 qubits
   • Limited coherence
   • No practical advantage yet
